# amnowls.github.io

Portfolio of Anna Nolden: interaction design, design technology.
Live at https://amnowls.github.io

Plain HTML, CSS and JavaScript, with no build step.

- **Edit the words:** `content/projects.js`. Every project, the bio and the links live there.
- **Look and behaviour:** `css/site.css`, `js/site.js`, `js/lcd.js`.
- **Media:** `media/` is generated from the original files by `tools/prepare_media.py` in the working folder (not in this repo).
- **Playable SPACE-OS:** `play/space-os/`. Music by Tottomori, used with permission.

Publish a change: commit, then `git push`. GitHub Pages updates within a minute or two.
